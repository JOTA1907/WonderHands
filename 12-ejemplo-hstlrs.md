# Fase 12 — Ejemplo de aplicación sin datos ficticios

El nombre del archivo se conserva por compatibilidad con la colección original de guías. Los productos, la estética y los textos de HSTLRS no son referencias para WonderHands y no deben pasar al sitio.

## Cómo transformar los materiales recibidos

1. Lista los archivos y anota cuáles muestran cada prenda real.
2. Forma para cada producto una ficha con nombre, descripción, precio, moneda y variantes confirmadas.
3. Selecciona una foto principal que permita reconocerlo y ordena las demás por utilidad.
4. Construye una ficha de estilo a partir de las imágenes y la identidad de WonderHands.
5. Diseña portada y tarjetas con esos datos; comprueba que la información de producto procede del catálogo.
6. Construye un mensaje de WhatsApp que incorpore la selección hecha en la ficha.
7. Verifica la web localmente y después bajo la ruta pública de GitHub Pages.

## Ejemplo de comprobación, sin inventar un producto

Si una prenda del catálogo tiene opciones llamadas Talla y Color, selecciona un valor que figure en una combinación real. El mensaje debe contener el nombre y el id de esa prenda, seguido de los dos valores seleccionados. Si cambias Color, el texto del enlace también debe cambiar. Si la combinación no existe, la página no debe construir un enlace de compra para ella.

Para un producto sin variantes, la página muestra nombre, precio, descripción, fotos y un botón cuyo mensaje omite talla y color. Para un producto con una sola foto, la galería no muestra controles vacíos.

## Criterio de éxito

Una persona puede explorar las prendas en celular, entender qué variantes están disponibles y abrir un chat con una consulta precisa. El sitio no presenta datos de otros proyectos ni valores inventados.
